# GameZone – Práctica 3 de Fundamentos de Sistemas Web

## Descripción
Sitio web temático de videojuegos desarrollado como práctica académica para aplicar HTML5, CSS3 y control de versiones.

## Tecnologías
- HTML5
- CSS3
- Git
- GitHub

## Funcionalidades
- Navegación mediante enlaces internos.
- Presentación temática y catálogo de videojuegos.
- Galería de seis imágenes.
- Enlaces externos e imágenes enlazadas.
- Tabla de ranking demostrativo.
- Formulario de contacto sin envío a servidor.
- Lista de comprobación de requisitos del equipo (reto práctico).
- Diseño adaptable a pantallas pequeñas.

## Estructura
- `index.html`: estructura del sitio.
- `css/estilos.css`: estilos externos.
- `imagenes/`: imágenes PNG locales.
- `README.md`: documentación del proyecto.
